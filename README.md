## Featured projects

> Much of my project work was built for enterprise clients, so the source code is private. The write-ups below describe the problem, my approach and the outcomes.

### 🔎 Insights Navigator: Agentic RAG for document intelligence
`Python` `LangGraph` `LLMs` `FastAPI` `Vector DB`

**Problem:** answering questions across large document corpora, where single-pass retrieval misses information spread across sections.
**What I built:** an agentic RAG application with multi-hop retrieval, dynamic document traversal and iterative self-correction.
**Evaluation:** I designed a benchmark covering Accuracy, Cross-Section Retrieval, Completeness, Fairness and Answer Relevance. On that benchmark the system outperformed GPT-4.5 by 0.25 points across all metrics.

### 🧩 OCU (One Customer Universe): Enterprise text-to-SQL
`Python` `LLMs` `FastAPI` `OWL` `Semantic Modelling` `PostgreSQL`

**Problem:** business users phrase questions in ambiguous, domain-specific terms that generic text-to-SQL handles poorly.
**What I built:** a text-to-SQL system on an ontology-driven semantic layer that encodes business logic and domain relationships, with semantic reasoning that resolves ambiguous intent and terminology into precise, context-aware SQL.
**Outcome:** measurable gains in query correctness over standard text-to-SQL baselines.

### 📊 Nuvation Patient Insights: Automated client reporting
`Python` `FastAPI` `Snowflake` `LLMs` `LangChain` `React`

**Problem:** recurring client reports took hours of manual analysis and slide-building.
**What I built:** a production system that turns raw data exports into board-ready PowerPoint decks, using automated analytics and data-grounded LLM narratives that users can edit before export.
**Outcome:** a multi-hour reporting cycle reduced to seconds with zero manual rework. Business users can reshape the analysis without engineering changes, which drove sustained adoption.
